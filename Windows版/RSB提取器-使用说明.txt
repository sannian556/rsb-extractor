RSB 提取器 —— 使用说明
================================================

【这是什么】
从安卓 APK 安装包里浏览文件，并把里面的 .smf 文件提取出来。
PvZ2 中国版的 .rsb.smf 外面套了一层 RSB 容器外壳，本工具会自动解开，
还原成工具箱和游戏都能直接认的 rsb1 文件。

------------------------------------------------
【运行环境】
Windows XP 及以上（.NET Framework 2.0 / 3.5 / 4.x 任意一个即可）：
  · XP          需要 .NET Framework 2.0 或更高
  · Win7        自带 3.5.1，直接能跑
  · Win8/10/11  自带的 .NET 4.x 就能跑

★「RSB提取器.exe」和「RSB提取器.exe.config」必须放在同一个文件夹里，
  两个文件缺一不可（config 不到 1 KB，作用是让新系统用 .NET 4.x 来跑）。

  嫌两个文件麻烦，可以用「RSB提取器(单文件免配置版).exe」——
  它一个文件就够，但要求系统装了 .NET Framework 4.0 以上
  （XP SP3 装了 .NET 4.0 也能用）。

------------------------------------------------
【怎么用】

1. 双击打开，用下面三种方式的任意一种把 apk 导入进来：
   · 点中间那个「导入 apk 文件」按钮，在文件对话框里选
   · 把 apk 文件直接拖到窗口里（拖进去时背景会泛一层淡蓝）
   · 在按钮下面那个输入框里粘贴 apk 的完整路径，按回车

2. 进入文件浏览界面（照着 Windows 资源管理器的样子做的）：

   顶上一条工具栏：
     · 「← 返回主界面」  回到最开始那个界面
     · 「←」「→」「↑」   后退 / 前进 / 上一级
     · 中间是地址栏（面包屑）——
        植物大战僵尸2_4.2.4.apk › assets › properties
       每一段都能点，点哪一段就跳到哪一层（当前这一层是加粗的）
     · 右边两个按钮切换显示方式：「详细信息」（带大小和类型） / 「大图标」

   左边是文件夹树，右边是当前文件夹里的内容，两边都带图标：
     · 文件夹、.xml、.png 这些用的是 Windows 自己的图标（和资源管理器同一套）
     · .smf 是本工具专门画的蓝色"资源包"图标，一眼就能认出来
     · 文件名显示成灰色的，表示它不是 .smf，选中了也不给导出

   操作：
     · 双击文件夹进去，或者直接点左边树上的目录
     · 选中文件之后，右下角的「导出smf文件」按钮才会亮起来；
       只是打开文件夹、没选文件的话，按钮一直是灰的
     · 按住 Ctrl 点可以一个一个多选，按住 Shift 可以选一片；
       松开 Ctrl 之后已经选中的不会掉
     · 最下面一条状态栏：左边是"共 N 项（x 个文件夹，y 个文件）"，
       右边是"已选 N 个文件"

3. 点「导出smf文件」进入导出界面：
   · 在输入框里填导出到哪个文件夹；或者点「选择文件夹」挑一个
     （这个是 Windows 自己的文件夹对话框，和资源管理器里那个一样）
   · 点「导出文件」就开始导出

4. 导出结束会弹一个框，写着「成功 N 个，失败 M 个」。
   点「确定」就回到最开始的主界面。
   如果有失败，框里会列出原因（比如"不是 .smf 文件"）。

5. 想换外观：主界面右下角有个「设置」按钮。
   · 外观三档：「跟随系统 / 浅色 / 深色」。
     如果这台电脑的 Windows 没有"深色模式"这个设置（Windows 10 1809 以下），
     「跟随系统」那一档会变灰用不了，另外两档照常能用。
   · 不想进设置页也行：导航栏右上的「外观：xxx」点开就能直接切。
   · 设置页最下面「关于」里写着版本号（当前是 1.0），报问题时先说这个。
   · 你选的那一档存在 %APPDATA%\RSB提取器\设置.txt，
     把那个文件删掉就恢复默认（跟随系统）。

------------------------------------------------
【导出规则】
· 只有 .smf 结尾的文件会被导出，其它类型一律跳过并计入失败
· .smf 里面如果是 RSB 容器外壳 → 自动解包成明文 rsb1 再写出
· 本来就是明文的 .smf（例如 ConfigManifest.json.smf）→ 原样导出
· 目标文件夹里有同名文件时自动加序号
  （dino.rsb.smf → dino_2.rsb.smf），不会覆盖已有文件
· 导出几百 MB 的大文件时界面会显示"正在导出… N / M"，不会卡死

------------------------------------------------
【命令行（可选，给批处理用）】
  RSB提取器.exe --open <apk>
      启动后直接导入并停在文件浏览界面

  RSB提取器.exe --open <apk> --dir assets --view large
      --dir  直接进到 apk 里的某个目录（这里是 assets）
      --view 初始显示方式：detail（详细信息，默认）/ large（大图标）

  RSB提取器.exe --open-export <apk> --out <文件夹> --multi 3
      直接进入导出界面，预填导出目录，并一次选中前 3 个 .smf

  路径里带空格的记得用引号括起来。

------------------------------------------------
【常见问题】

Q: 提示"找不到 ZIP 结尾记录"或"不是 ZIP/APK"？
A: 这个 apk 不是标准 zip 结构（有些加固包会改），本工具打不开。

Q: 导出后文件名还是 .rsb.smf，但内容变了？
A: 这是有意的 —— 解开 RSB 容器之后文件名保持不变，
   PvZ 2 SHUTTLE Toolkit 这类工具照样按 .rsb.smf 认它。

Q: 杀毒软件报毒？
A: 本程序不联网、不写注册表、不设开机自启；
   只读你选中的 apk，只写你指定的输出文件夹。
   报毒一般是"没有数字签名 + 新文件"引起的启发式误报，
   加进信任区即可。

Q: 怎么确认手上这份是不是最新版、有没有被人改过？
A: 版本号：双击打开 → 右下角「设置」→「关于」那一行（当前是版本 1.0）。
   校验值：在 exe 所在文件夹按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，运行
     Get-FileHash .\RSB提取器.exe -Algorithm SHA256
   和发布时给的 SHA256 对一下即可。注意每次重新编译，哈希都会变。

Q: 选了一堆文件，为什么只导出了一部分？
A: 只有 .smf 会被导出，别的类型会在弹窗里列为失败。

Q: 程序突然闪退或者界面空白？
A: 会在 %TEMP%\RSB提取器-crash.log 里留下详细错误信息，
   把那个文件发过来就能定位。

------------------------------------------------
【技术备注】
· 单文件程序，零第三方依赖；内置 7-Zip 的 LZMA 解码器（public domain）
· RSB 容器格式（实测自 植物大战僵尸2 4.2.4 的 33 个包，全部通过校验）：
    头 32 字节 : "RSLB" | 版本 | 未压缩总大小 | 压缩区大小 | 块大小 | 块数
    块表 N*36  : 未压缩偏移 | 未压缩大小 | 压缩偏移 | 压缩大小 | props | 字典
    每块数据   : 5 字节 LZMA 头（props + 字典）+ raw LZMA1 流
· 每块的 LZMA 参数是从该块自己的头里读的，所以不同包、甚至同一个包
  里不同块参数不一样也能正确处理。
· 文件图标是通过 SHGetFileInfo 向 Windows 要的（只把扩展名告诉它），
  所以 apk 里的文件不用解出来也能显示正确的系统图标。
